## 🚀 Projetos em destaque

### 📊 TCE-CE Data Pipeline & Risk Analytics

Pipeline de dados desenvolvido para coletar, processar e analisar informações públicas de APIs do Tribunal de Contas do Estado do Ceará.

**Principais tecnologias:**
- Python, Pandas e APIs REST
- JSON e Parquet
- DuckDB e SQL
- Streamlit e Docker
- OCR com OpenCV e Tesseract
- Machine Learning com Scikit-learn

**Principais funcionalidades:**
- Extração e integração de dados de diferentes endpoints.
- Tratamento, normalização e relacionamento de registros.
- Processamento e armazenamento em formato colunar.
- Análise de risco, identificação de anomalias e agrupamento de municípios.
- Extração de informações de documentos por OCR.
- Disponibilização de análises por meio de dashboards.

### ⚙️ Modernização de Sistema de Controle de Equipamentos

Refatoração de um sistema legado para uma arquitetura baseada em Laravel e React, com foco na manutenção das regras de negócio, integração com banco de dados e evolução das funcionalidades.

**Principais tecnologias:**
- PHP e Laravel
- React e JavaScript
- MySQL e SQL
- Python para automação e migração de dados
- Docker e Linux
- Redis, filas e processamento assíncrono

**Principais atividades:**
- Refatoração de funcionalidades e regras de negócio.
- Migração e integração de dados entre sistemas.
- Manutenção e evolução de APIs.
- Investigação de falhas e otimização de consultas.
- Desenvolvimento de funcionalidades para controle de equipamentos, movimentações e relatórios.
